# Bento Building Surface Splitter

Blender 4.2+ 建筑内外墙辅助拆分插件。插件只使用 Blender 自带的
`bpy`、`bmesh` 和 `mathutils`，不需要安装额外 Python 包。

## 从 Unity 启动

在 Bento的“资源、模型和预制体 > Blender 建筑拆分”页面：

1. 在 Project 面板选中一个 FBX。
2. 首次使用时指定本机 `blender.exe`。
3. 点击“在 Blender 中打开选中 FBX”。

Unity 会启动 Blender、临时启用仓库中的插件、导入 FBX，并把默认输出路径设为
`原文件名_processed.fbx`。这个过程不会修改或覆盖原 FBX。

## Blender 工作流

### 0. 必须先准备地板

插件的横面切线和部分内外判断非常依赖地板轮廓。地板准备错误时，
后续即使调整容差，也可能得到大面积误判。

地板要求：

- 必须从建筑主体中分离为独立网格对象。
- 名称必须包含 `地板`、`地面`、`floor` 或 `ground`。
- 只保留水平顶面，不要混入墙、柱、屋顶、台阶或向下延伸的厚侧面。
- 外轮廓应准确贴合室内边界，凹角、缺口和不规则区域不能用一个大矩形代替。
- 一块平面可以由多个共面的多边形组成；重点是没有混入立体结构。
- 多层或多个不连通区域可以分别使用多个地板对象。

### Blender 新手：分离地板的默认快捷键

1. 选中建筑模型，按 `Tab` 进入编辑模式。
2. 按主键盘数字 `3` 切换为面选择。
3. 左键选择地板面；按住 `Shift` 点击可增减选择。
4. 地板面彼此连通的时候，把鼠标放在地板上按 `L` 可选择连通网格。
5. 确认没有选中墙、柱、屋顶或侧面。
6. 按 `P`，选择“选中项（Selection）”。
7. 按 `Tab` 返回对象模式。
8. 选中新对象，按 `F2`，命名为“地板”“地面”“Floor”或“Ground”。

如果原模型没有沿地板轮廓分面，可以在编辑模式按 `K` 使用小刀工具：
左键逐点画出轮廓，按 `Enter` 确认，然后再选择地板面并执行
`P > 选中项`。切割前建议保存 `.blend`，切错可用 `Ctrl+Z`。

分离后建议进入顶视图检查轮廓：小键盘 `7`，或者点击右上角视图导航器。
地板法线异常时，在编辑模式全选地板面并按 `Shift+N` 重新计算外侧法线。

### 面板步骤

1. 创建一个或多个室内方块，缩放到填满室内空间，但不要穿墙。
2. 选中屋顶或其他无需计算的对象，点击“排除选中对象”。
3. 根据地板轮廓执行横面候选、预览和切分。
4. 选择待处理对象并点击“计算内外分类”。
5. 使用“选择室内面 / 选择外墙面”进入编辑模式检查结果。
6. 选中误判面，用手动修补按钮保存正确分类。
7. 点击“确认并分离”，然后导出新 FBX。

当前版本按面拆分并保留材质槽、UV 和平滑标记。原始对象保留不动。
LOD、复杂自定义网格属性、形态键和蒙皮网格将在后续版本中专项验证。
