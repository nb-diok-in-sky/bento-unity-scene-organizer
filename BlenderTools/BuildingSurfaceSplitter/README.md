# Bento Building Surface Splitter

Blender 4.2+ 建筑内外墙辅助拆分插件。插件只使用 Blender 自带的
`bpy`、`bmesh` 和 `mathutils`，不需要安装额外 Python 包。

## 从 Unity 启动

在 Bento的“资源、模型和预制体 > Blender 建筑拆分”页面：

1. 在 Project 面板选中一个 FBX。
2. 首次使用时指定本机 `blender.exe`。
3. 点击“在 Blender 中打开选中 FBX”。

Unity 会启动 Blender、临时启用仓库中的插件、导入 FBX，并把默认输出路径设为
`原文件名_processed.fbx`。这个过程不会修改或覆盖原 FBX。

## Blender 工作流

1. 创建一个或多个室内方块，缩放到填满室内空间，但不要穿墙。
2. 选中屋顶或其他无需计算的对象，点击“排除选中对象”。
3. 选择待处理对象并点击“计算内外分类”。
4. 使用“选择室内面 / 选择外墙面”进入编辑模式检查结果。
5. 选中误判面，用“选中面 → 室内 / 外墙 / 排除”修正。
6. 点击“确认并分离”，然后导出新 FBX。

当前版本按面拆分并保留材质槽、UV 和平滑标记。原始对象保留不动。
LOD、复杂自定义网格属性、形态键和蒙皮网格将在后续版本中专项验证。
