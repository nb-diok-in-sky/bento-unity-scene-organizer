# Bento使用说明

> 面向美术、地编和需要整理 Unity 资源的使用者。

> 不需要了解代码，按照本文选择功能、查看预览、确认执行即可。

## 一、这是什么

Bento是一套 Unity 编辑器工具，主要解决以下问题：

- Project 文件夹太多，常用目录不好找。

- 大量对象或资产需要批量改名。

- 已经被场景或 Prefab 引用的资产需要安全移动。

- 外部模型需要创建材质、绑定贴图并生成 Prefab。

- 场景中的父子层级、材质、光源、阴影需要批量处理。

- 检查场景里的 FBX 实例或模型穿插。

- 在 Blender 中辅助拆分建筑内墙和外墙。

## 二、打开工具箱

在 Unity 顶部菜单选择：

`Tools/Bento > Bento`

工具箱左侧分为：

- 常用

- 整理

- 资源、模型和预制体

- 材质

- 场景

窗口较窄时，左侧列表会变成顶部的“分类”和“功能”下拉框。

#### 收藏常用功能

每个功能旁边都有 ☆。

点击 ☆：加入“常用”。

点击 ★：从“常用”移除。

收藏只保存在当前电脑，不会提交到 Git 或影响其他人。

建议先收藏自己经常使用的功能，例如：

- 文件夹收藏

- 批量重命名

- 资产移动

- 选中模型材质贴图

- Hierarchy 整理

收藏之后就可以在“常用”中找到对应功能。

## 三、使用前必须知道

### 先看预览，再执行

只要页面提供“扫描”“分析”“计划”或“预览”，都应该先执行这一步，检查列表后再确认。

### 场景操作和资产操作的撤销方式不同

场景对象操作通常支持 Ctrl+Z。

Project 资产的移动和重命名不能依赖普通 Ctrl+Z。

资产工具会使用 GUID 验证、操作历史或“恢复上次操作”进行恢复。

> 总的来说，大部分场景功能可以使用 Ctrl+Z 撤销；不能依赖 Ctrl+Z 的资产操作会提供恢复入口。

### 不要在 Play Mode 中整理资产

移动、重命名、生成变体和替换预制体前，先退出运行模式。

### 不要混选 Hierarchy 和 Project

使用“批量重命名”等工具时，只选择一种：

- Hierarchy 中的场景对象；或

- Project 中的资产。

### 高风险按钮会明确标出

例如“替换所有 Build Settings 场景”会直接保存多个场景，不能使用一次 Ctrl+Z 跨场景撤销。没有明确需要时不要使用。

## 四、整理

### 文件夹收藏

什么时候用： Project 文件夹太多，经常找不到常用目录。

**怎么用：**

从 Project 窗口把文件夹拖入页面。

点击“加入收藏”。

以后点击收藏名称即可在 Project 中定位该文件夹。

支持排序、删除收藏和清理已经不存在的文件夹。

### 批量重命名

什么时候用： 一次修改多个场景对象或 Project 资产的名称。

**工具会自动判断当前是：**

Hierarchy 场景对象模式；或

Project 资产模式。

#### 统一改成同一个基础名称

填写：

前缀

基础名称

后缀

是否自动编号

例如：

建筑_墙体01_完成

建筑_墙体02_完成

#### 单独增加前后缀

勾选“单独增加前后缀”，每个对象保留原名。

例如原名：

桌子

椅子

火把

前缀填写 村庄_，后缀填写 _场景：

村庄_桌子_场景

村庄_椅子_场景

村庄_火把_场景

**安全说明：**

Hierarchy 对象支持一次 Ctrl+Z 撤销。

Project 资产通过 Unity 安全改名，保持 .meta、GUID 和已有引用。

Project 改名完成后可以使用操作历史恢复。

### 资产移动

什么时候用： 把 Project 中选中的 Prefab、FBX、材质、贴图、普通资产或文件夹移动到指定目录。

**怎么用：**

在 Project 中选择要移动的资产。

分别指定模型、材质、贴图和其他资产的目标文件夹。

点击“扫描 Project 选择”。

检查移动计划和警告。

点击“确认并安全移动勾选资源”。

页面还可以：

导出移动前完整清单。


反向恢复上次移动。

**安全说明：**

使用 Unity 的 AssetDatabase.MoveAsset。

.meta 和 GUID 保持不变。

每次移动后都会验证 GUID 和资产能否加载。

中途失败会尝试自动回滚。

不会自动把没有选中的依赖一起移动。

### 操作历史

什么时候用： 恢复通过 Bento完成的资产移动或资产重命名。

**怎么用：**

点击“刷新历史”。

找到对应操作记录。

点击“按 GUID 恢复此批操作”。

注意： 操作历史不是 Git 的替代品。重要操作仍应在版本控制可恢复的环境中执行。



### AI资产整理

什么时候用： 希望 AI 对指定资产范围生成分类计划。

**怎么用：**

指定来源根目录。

指定模型、材质、贴图和其他资产的输出文件夹。

点击“扫描并生成整理计划”。

人工检查每条计划。

点击“确认执行勾选计划”。

**安全说明：**

AI 只能读取指定范围并生成计划。

AI 不会绕过页面直接移动资源。

最终执行必须由用户确认。

底层复用“资产移动”的安全移动服务。

需要Unity MCP 可以让codex一键帮你装一个

### 资产信息

什么时候用： 查看 Prefab、FBX 或文件夹中的对象结构，并给 AI 地编或资产审查提供数据。

**怎么用：**

在 Project 中选择 Prefab、FBX 或文件夹。

点击“分析 Project 选择”。

需要保存时点击“导出 JSON”。

会修改什么： 只读分析，不修改资产。

### 按后缀清理

什么时候用： 删除资产包中明确不需要的文件，例如 .max、.psd 或指定 LOD 文件。

**怎么用：**

选择要检查的 Project 文件夹。

每行填写一个文件名结尾。

点击“① 递归扫描”。

检查并勾选结果。

点击“② 删除”。

危险： 这是删除功能。必须检查完整列表后再执行，并提前确认版本控制可以恢复。

### 递归抽取资产

什么时候用： 从多层子目录中找出指定类型资产，并集中移动到一个目录。

**怎么用：**

指定来源文件夹和目标文件夹。

选择要抽取的资产类型。

点击“① 递归扫描”。

检查冲突和目标路径。

点击“② 平铺移动”。

支持“恢复上次移动”。

安全说明： 使用 Unity 安全移动，保持 GUID 和已有引用。

> 用了就知道了 总之就是资产移动工具

### Hierarchy 整理

> 好用！！

什么时候用： 一次把大量场景对象放入指定父节点，或创建新的空父物体进行分组。

#### 快速把对象放入固定父节点

只选一个目标父物体。

点击“缓存当前选中为父物体”。

多选需要归入的对象。

点击归入按钮。

缓存不会因为 Selection 改变而丢失。

所以缓存了物体之后可以先去干别的，选择调整别的物体之后再进行整理

#### 创建空父物体

多选场景对象。

输入空物体名称。

点击“创建并归入”。

有了这个功能就可以改变工作方式 先选择想要合并的物体 之后用这个按钮就可以一键组合

将这个功能 和 "快速把对象放入固定父节点" 组合使用  可以将组合起来的物体放到整体的父物体里面

#### 变换风险和补偿节点

当对象带有“旋转 + 非等比缩放”组合0时，直接换父级可能发生形变。工具会阻止普通执行，并显示：

独立补偿：每个风险对象创建一个补偿节点。

共享补偿：同一原父节点下的对象共用一个补偿节点。

没有风险时不会显示补偿选项。

安全说明： 保持世界位置、旋转和缩放，整批操作支持一次 Ctrl+Z。

这个会独立在节点里面生成一个新的父物体 用以防止形变！！！注意！！！

### 场景光源批处理

什么时候用： 批量把选中对象及其子物体中的 Light 改为无阴影、硬阴影或软阴影。

**怎么用：**

在 Hierarchy 选择光源或包含光源的父节点。

选择目标阴影模式。

检查识别到的光源数量。

点击修改按钮。

支持 Ctrl+Z。

### 场景物体阴影

什么时候用： 批量修改 Renderer 是否投射阴影、是否接收阴影。

**怎么用：**

在 Hierarchy 选择对象或父节点。

选择要修改“投射阴影”还是“接收阴影”。

检查 Renderer 数量。

点击修改按钮。

支持 Ctrl+Z。

### 几何相交审查

什么时候用： 检查场景模型是否存在明显的几何穿插，或给 AI 白盒搭建提供检查结果。

**怎么用：**

选择扫描范围。

设置是否包含未激活对象等选项。

点击“执行只读扫描”。

在结果中定位 A、定位 B 或同时选中。

会修改什么： 只读扫描。结果只缓存在内存中，点击“清空内存结果”即可删除。

## 五、资源、模型和预制体

### 模型导入

什么时候用： 连续处理一个或多个外部模型文件夹。

**流程为：**

递归扫描 FBX 和贴图

→ 创建并绑定 URP/Lit 材质

→ 生成 Prefab

**怎么用：**

添加一个或多个来源文件夹。

设置材质和 Prefab 输出选项。

点击“① 扫描并预览整条流程”。

检查每个 FBX 的材质和 Prefab 计划。

点击“② 执行”。

 用的少

### 资源变体

什么时候用： 把场景内已经调整好的 Prefab、FBX 或普通对象保存为新的独立 Prefab。

可选复制：

Prefab

材质

贴图

复制后会把新 Prefab 重新引用到新材质和新贴图，原资产保持不动。

**推荐步骤：**

在 Hierarchy 选择对象。

指定 Prefab、材质和贴图输出文件夹。

设置命名。

点击“分析选中对象”或“仅干运行”。

检查结果后生成。

支持“一键完整撤销本次生成”。

> 用来制作变体的 可以省去重新建造材质球或者复制贴图的时间

### Blender 建筑内外墙

这是 Unity 与仓库内 Blender 插件的启动入口，详细用法见本文最后的 Blender 章节。

不用 Blender 的使用者可以忽略该功能，不需要安装任何额外依赖。

### FBX 材质继承

什么时候用： 一个模型的材质引用正确，另一个同结构模型需要复制它的材质。

**怎么用：**

指定参考模型。

指定待修复模型。

点击“对比同名子物体并匹配材质”。

检查匹配结果。

点击“将材质复制到待修复模型”。

工具按照子物体路径或唯一同名 Renderer 进行匹配。

### FBX 快速导入

什么时候用： 单独处理一个 FBX，或对一批命名较规范的 FBX 快速创建材质。

**单个 FBX 支持：**

锁定选中 FBX。

载入选中贴图。

自动判断 BaseColor、Normal、Metallic、AO、Height、Emission。

创建 URP/Lit 材质并映射到 FBX。

直接生成 Prefab。

**批量入口支持：**

扫描文件夹中的 FBX 和贴图组。

批量创建并绑定 URP 材质。

批量创建 Prefab。

如果需要连续处理多个完整目录，优先使用“模型导入”。

> 一般项目不用 项目使用的是自定义的shader而非标准的urp

### Prefab Layer

什么时候用： 为 Project 中的 Prefab 规划并写入 Layer。

**怎么用：**

在 Project 中选择 Prefab。

点击“分析 Project 选择”。

检查每个节点的建议 Layer。

点击“确认应用 Layer 计划”。

默认只修改 Default 节点，已有的特殊 Layer 会保留。支持恢复上次修改。

> 用的少

### Tag/Layer

什么时候用： 批量修改 Hierarchy 场景对象及其子物体的 Tag 或 Layer。

**怎么用：**

在 Hierarchy 选择一个或多个对象。

选择目标 Tag 或 Layer。

决定是否包含子物体。

点击应用。

支持 Ctrl+Z。

## 六、材质

### Shader 替换

什么时候用： 批量把 Project 中选中的材质球切换到另一个 Shader。

**怎么用：**

在 Project 中选择材质球。

选择目标 Shader。

点击替换按钮。

如果换 Shader 后贴图丢失，可以使用同页的“恢复丢失属性”尝试从材质序列化数据恢复。

### 贴图扫描

什么时候用： 统计资产包的贴图后缀，并建立后缀到贴图类型的识别规则。

**怎么用：**

在 Project 中选择贴图或文件夹。

点击“扫描选中的贴图”。

检查后缀、出现次数和识别类型。

设置改名后的输出后缀。

需要复用时保存为预设。

### 贴图改名

什么时候用： 根据“贴图扫描”中确认的规则批量修改贴图名称。

必须先完成贴图扫描。

**怎么用：**

打开“贴图扫描”并完成扫描与规则设置。

切换到“贴图改名”。

检查完整改名预览。

点击“执行改名”。

### 填充材质球

什么时候用： 根据贴图名称，将一批贴图自动匹配到材质球槽位。

**怎么用：**

指定贴图文件夹。

在 Project 中选择材质球并锁定。

点击“扫描匹配贴图”。

检查每个材质对应的贴图。

点击“执行填充”。

### 选中模型材质贴图

什么时候用： 已经选中场景模型、Prefab 或 FBX，希望快速找到它实际使用的模型、材质和贴图。

**怎么用：**

在 Hierarchy 选择模型，或在 Project 选择 Prefab/FBX。

点击“锁定当前物体并扫描”。

使用“只选模型”“只选材质”“只选贴图”。

需要整理时，在页面下方指定三类目标文件夹并安全移动。

普通模型扫描会忽略 Terrain，防止把当前场景的地形贴图混进结果。


### 选中 Terrain 绘制贴图

什么时候用： 在 Terrain Paint Texture 中选中了某一层，希望在 Project 中找到对应贴图。

**怎么用：**

选择 Terrain。

打开 Paint Texture。

点击需要定位的图层。

点击“在 Project 中选中当前 Paint Texture 贴图”。

> 这个功能是用于直接选中对应的贴图文件而不是选中terrain的素材数据

### 一键处理

什么时候用： 资产包的贴图和材质命名比较规则，希望按已有规则批量扫描、改名并填充。

**怎么用：**

选择资产根文件夹。

点击“扫描文件夹结构”。

检查识别结果。

选择需要执行的步骤。

点击“执行批量处理”。

首次处理命名混乱的资产包时，优先使用分开的“贴图扫描”“贴图改名”和“填充材质球”，不要直接一键执行。

> 这个也用的比较少  不是特别适配项目可能

### 材质修复

什么时候用： Standard 转 URP 后，材质仍有贴图槽、关键字或渲染状态不一致。

**怎么用：**

扫描全部材质、指定文件夹或当前选择。

查看异常数量和原因。

勾选需要修复的材质。

点击“修复选中的材质”。

> 别用



### URP 材质恢复

什么时候用： 材质 Shader 丢失、变成 Error Shader，或需要迁移到 Universal Render Pipeline/Lit。

**可以：**

载入选中材质。

收集选中 Prefab 引用的材质。


扫描指定目录。

执行前可以逐项筛选和定位。

限制： 只能恢复常见 PBR 属性。原自定义 Shader 的风、顶点动画、混合层或其他专属效果无法自动复刻。

> 别用

## 七、场景

### 场景材质替换

什么时候用： 把 Hierarchy 选中对象及其子物体中使用的某个旧材质，统一替换为新材质。

**怎么用：**

在 Hierarchy 选择要处理的对象或父节点。

指定旧材质。

指定新材质。

检查材质槽数量。

点击替换。

支持 Ctrl+Z。

> 一句话:替换物体里面的你不想要的材质 ..

常常用于新导入进来的fbx物体

### 场景材质吸管

什么时候用： 场景模型包含多个材质，不知道鼠标所指区域对应哪个材质球。

**怎么用：**

点击“开始吸取材质”。

在 Scene 视图点击模型表面。

工具会在 Project 中定位对应材质球。

按 Esc 或点击“停止吸取”退出。

### 预制体替换

什么时候用： 把 Hierarchy 中选中的对象替换成另一个 Prefab 或 FBX。

**支持：**

只替换当前选中的对象。

按名称替换当前场景。

高风险：替换所有 Build Settings 场景。

可以选择保留原对象的位置、旋转和缩放。

**安全说明：**

当前场景替换支持 Ctrl+Z。

“所有 Build Settings 场景”会保存场景文件，无法跨场景一次撤销。

> 好用

### FBX 实例检查

什么时候用： 检查场景里是否直接放入了 FBX/OBJ，而不是项目规范要求的 Prefab。

**怎么用：**

选择检查当前选择或已加载场景。

点击“开始检查”。

搜索、筛选、定位或批量选中结果。

会修改什么： 只读检查，不会自动替换对象。

> 检查是否存在fbx物体在场景里

## 八、可选功能

部分功能依赖额外 Unity 包。没有安装时，对应页面会自动隐藏，其余工具正常使用。

### OBJ 转项目 FBX

需要 Unity 官方 FBX Exporter。

**用途是：**

将 OBJ 导入结果重新导出为项目 FBX。

创建项目材质。

在确认 FBX 和材质引用正常后，扫描并删除可安全移除的 OBJ/MTL 源文件。

> 少用

### AI/MCP

需要 MCP for Unity。

用途是让 AI：

读取选择和场景层级。

生成只读审查结果。

生成资产整理或 Hierarchy 整理草案。

调用几何相交和 FBX 实例检查。

## 九、Blender 建筑内外墙拆分

### 这个 Blender 插件怎么处理

Blender 插件已经放在 Bento仓库中：

BlenderTools/BuildingSurfaceSplitter

它是一个可选功能：

只使用 Unity 工具的使用者不需要安装 Blender，也不受影响。

需要拆分建筑内外墙的使用者，从 Unity 页面一键启动即可。

Blender 路径只保存在各自电脑的 EditorPrefs，不会上传 Git。

插件不参与 Unity C# 编译。

### 环境要求

Blender 4.2 或更高版本。

不需要安装额外 Python 包。

### 从 Unity 启动

**入口：**

资源、模型和预制体 > Blender 建筑内外墙

**步骤：**

在 Project 中选择一个 FBX。

首次使用时点击“自动查找”或“浏览”，指定 blender.exe。

点击“在 Blender 中打开选中 FBX”。

Unity 会：

启动 Blender。

临时加载仓库中的插件。

导入选中 FBX。

打开右侧 N 面板中的 Bento 页签。

原 FBX 默认不会被覆盖。

### Blender 面板工作流

在 Blender 右侧 Bento 面板中，按照编号操作。

#### 最重要：先准备独立地板

这个插件非常依赖地板对象。地板不仅是普通模型的一部分，它会被用作室内范围、横面候选和切线轮廓的重要判断依据。

**合格地板必须满足：**

地板必须从建筑模型中单独分离成独立对象。

对象名称中必须包含“地板”“地面”“floor”或“ground”，否则插件不会把它识别为地板。

地板应当是一块水平平面，不要带墙、柱子、台阶、屋顶或向下延伸的厚侧面。

地板外轮廓必须贴合真实室内边界。门洞、缺口、凹角和不规则房间轮廓要整理正确。

不要拿一个巨大矩形随便盖住整栋建筑，否则切线和室内外判断会沿错误轮廓计算。

多个互不相连的楼层或房间，可以分别保留为多个独立地板对象，并把名称写清楚。

这里所说的“一块平面”，是指只保留地板顶面的平面网格。平面内部可以由多个面组成，但不应该混入墙体或其他立体结构。

#### 不会 Blender 时，怎样把地板分离出来

下面是 Blender 默认键位：

1. 在右上角 Outliner 或 3D 视图中选中建筑模型。

2. 按 Tab 进入编辑模式。

3. 按 3 切换到面选择模式。注意这里是主键盘数字 3，不是小键盘。

4. 选择地板面：

   鼠标左键选择一个面。

   按住 Shift 再点击，可以增加或取消选择。

   如果地板面彼此连通，可以把鼠标放到地板上按 L，选择鼠标位置对应的连通网格。

   误选时按 Alt+A 取消全部选择，再重新选择。

5. 确认只选中了地板顶面，没有选到墙、柱、屋顶和底部侧面。

6. 按 P 打开“分离”菜单。

7. 选择“选中项（Selection）”。

8. 按 Tab 返回对象模式。

9. 新分离出的对象通常仍是自动名称。选中它，按 F2，改名为“地板”“地面”“Floor”或“Ground”。

如果地板和其他结构完全连在一起，不容易选择：

可以在编辑模式按 K 使用小刀工具，先沿真实地板轮廓补切。

左键逐点绘制切线，按 Enter 确认切割。

再按 3 进入面选择，选中切出的地板面，最后按 P > 选中项进行分离。

小刀切割前建议先保存一份 .blend，切错时使用 Ctrl+Z 撤销。

**地板分离后的检查：**

单独选中地板，按小键盘 7 切换顶视图；没有小键盘时使用右上角视图导航器进入顶视图。

确认轮廓与室内边界一致，没有跨出外墙，也没有漏掉明显凹角。

按 Tab 进入编辑模式，确认只有平面，没有墙体、柱子或向下的厚度。

地板法线应朝上。如果显示异常，可以全选地板面后按 Shift+N 重新计算外侧法线。

完成后再回到 Bento 面板进行横面切线和自动分类。

#### 确认处理对象

确认待处理网格范围。Unity 启动时导入的模型会作为默认目标。

#### 创建室内方块并排除对象

创建一个或多个室内方块：

缩放到填满室内空间。

不要穿过墙体。

多个房间可以使用多个方块。

屋顶、装饰或不需要参与判断的对象，可以使用“排除选中对象”。

#### 网格预处理

对于跨越室内外边界的大横面，需要先切分。

开始这一阶段前，必须已经准备好独立且轮廓正确的地板对象。页面提示“没有可用地板轮廓”时，不要继续乱调容差；先检查地板是否已分离、名称是否包含地板关键词、是否为向上的平面。

推荐顺序：

计算候选面

→ 手工增减选择

→ 保存当前选择为候选面

→ 生成切线预览

→ 确认并执行切分

→ 查看实际切割结果

预览不会立即改动最终分类。执行切分前应检查候选面和切线。

#### 自动分类

点击“自动分类”。

工具结合室内方块、面朝向、射线和地板轮廓等规则，将面标记为：

室内面

外墙面

排除

#### 查看分类结果

使用：

选择室内面

选择外墙面

进入编辑模式检查分类。

#### 手动修补

如果存在误判：

手工增减面选择。

点击“保留选中面为室内/外墙”，追加修正。

或点击“覆盖保存为室内/外墙”，用当前选择覆盖该分类。

#### 生成分类对象并导出

**设置：**

室内对象名称

外墙对象名称

屋顶名称

是否替换源对象

输出 FBX 名称和目录

确认后执行分离，再导出新的 FBX。

#### Blender 插件当前限制

适合静态建筑网格。

会保留常规材质槽、UV 和平滑标记。

蒙皮模型、形态键、复杂自定义属性和特殊 LOD 结构没有完整保证。

自动分类不是最终答案，必须人工检查室内面和外墙面。

地板轮廓错误会直接影响横面切线和部分室内外判断。遇到大面积误判时，先检查地板，不要第一时间调整所有高级参数。

“分类规则调试”是排查算法用的高级区域，普通使用者无需展开。

## 十、推荐工作流

### 导入一个新资产包

`文件夹收藏 → 模型导入 → 选中模型材质贴图 → 批量重命名 → 资产移动 → Prefab Layer`

### 整理一个现有场景

`FBX 实例检查 → Hierarchy 整理 → 场景材质替换 → 场景光源批处理 → 场景物体阴影 → 几何相交审查`

### 把场景中调好的对象保存为新资产

`资源变体 → 检查新材质和贴图引用 → 批量重命名 → 资产移动`



## 十一、遇到问题先检查

是否处于 Play Mode。

当前选择是在 Hierarchy 还是 Project。

页面要求的是资产、文件夹、Prefab、FBX 还是场景对象。

是否先执行了扫描或分析。

计划列表中是否有黄色或红色警告。

Blender、FBX Exporter 或 MCP 是否属于当前功能的可选依赖。

资产操作出错时，先停止继续操作，查看“操作历史”或版本控制，不要重复执行。
