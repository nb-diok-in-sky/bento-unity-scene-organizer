# Bento 使用说明

> 面向美术、地编和需要整理 Unity 资源的使用者。

> 不需要了解代码，按照本文选择功能、查看预览、确认执行即可。

## 一、这是什么

Bento 是一套 Unity 编辑器工具，主要解决以下问题：

- Project 文件夹太多，常用目录不好找。

- 大量对象或资产需要批量改名。

- 已经被场景或 Prefab 引用的资产需要安全移动。

- 外部模型需要创建材质、绑定贴图并生成 Prefab。

- 场景中的父子层级、材质、光源、阴影需要批量处理。

- 检查场景里直接引用的 FBX 实例。

## 二、打开工具箱

在 Unity 顶部菜单选择：

`Tools > Bento > 工具箱`

工具箱左侧分为：

- 常用

- 整理

- 资源、模型和预制体

- 材质

- 场景

窗口较窄时，左侧列表会变成顶部的“分类”和“功能”下拉框。

#### 收藏常用功能

每个功能旁边都有 ☆。

点击 ☆：加入“常用”。

点击 ★：从“常用”移除。

收藏只保存在当前电脑，不会提交到 Git 或影响其他人。

建议先收藏自己经常使用的功能，例如：

- 文件夹收藏

- 批量重命名

- 资产移动

- 选中模型材质贴图

- Hierarchy 整理

收藏之后就可以在“常用”中找到对应功能。

## 三、使用前必须知道

### 先看预览，再执行

只要页面提供“扫描”“分析”“计划”或“预览”，都应该先执行这一步，检查列表后再确认。

### 场景操作和资产操作的撤销方式不同

场景对象操作通常支持 Ctrl+Z。

Project 资产的移动和重命名不能依赖普通 Ctrl+Z。

资产工具会使用 GUID 验证、操作历史或“恢复上次操作”进行恢复。

> 总的来说，大部分场景功能可以使用 Ctrl+Z 撤销；不能依赖 Ctrl+Z 的资产操作会提供恢复入口。

### 不要在 Play Mode 中整理资产

移动、重命名、生成变体和替换预制体前，先退出运行模式。

### 不要混选 Hierarchy 和 Project

使用“批量重命名”等工具时，只选择一种：

- Hierarchy 中的场景对象；或

- Project 中的资产。

### 高风险按钮会明确标出

例如“替换所有 Build Settings 场景”会直接保存多个场景，不能使用一次 Ctrl+Z 跨场景撤销。没有明确需要时不要使用。

## 四、整理

### 文件夹收藏

什么时候用： Project 文件夹太多，经常找不到常用目录。

**怎么用：**

从 Project 窗口把文件夹拖入页面。

点击“加入收藏”。

以后点击收藏名称即可在 Project 中定位该文件夹。

支持排序、删除收藏和清理已经不存在的文件夹。

### 批量重命名

什么时候用： 一次修改多个场景对象或 Project 资产的名称。

**工具会自动判断当前是：**

Hierarchy 场景对象模式；或

Project 资产模式。

#### 统一改成同一个基础名称

填写：

前缀

基础名称

后缀

是否自动编号

例如：

建筑_墙体01_完成

建筑_墙体02_完成

#### 单独增加前后缀

勾选“单独增加前后缀”，每个对象保留原名。

例如原名：

桌子

椅子

火把

前缀填写 村庄_，后缀填写 _场景：

村庄_桌子_场景

村庄_椅子_场景

村庄_火把_场景

**安全说明：**

Hierarchy 对象支持一次 Ctrl+Z 撤销。

Project 资产通过 Unity 安全改名，保持 .meta、GUID 和已有引用。

Project 改名完成后可以使用操作历史恢复。

### 资产移动

什么时候用： 把 Project 中选中的 Prefab、FBX、材质、贴图、普通资产或文件夹移动到指定目录。

**怎么用：**

在 Project 中选择要移动的资产。

分别指定模型、材质、贴图和其他资产的目标文件夹。

点击“扫描 Project 选择”。

检查移动计划和警告。

点击“确认并安全移动勾选资源”。

页面还可以：

导出移动前完整清单。保存位置由你选择，会同时生成一份 JSON 和一份便于阅读的 .txt，下次会记住上次选的文件夹。

反向恢复上次移动。

**安全说明：**

使用 Unity 的 AssetDatabase.MoveAsset。

.meta 和 GUID 保持不变。

每次移动后都会验证 GUID 和资产能否加载。

中途失败会尝试自动回滚。

不会自动把没有选中的依赖一起移动。

### 操作历史

什么时候用： 恢复通过 Bento 完成的资产移动或资产重命名。

**怎么用：**

点击“刷新历史”。

找到对应操作记录。

点击“按 GUID 恢复此批操作”。

注意： 操作历史不是版本控制系统的替代品。重要操作仍应在版本控制可恢复的环境中执行。

### 资产信息

什么时候用： 查看 Prefab、FBX 或文件夹中的对象结构，并给 AI 地编或资产审查提供数据。

**怎么用：**

在 Project 中选择 Prefab、FBX 或文件夹。

点击“分析 Project 选择”。

需要保存时点击“导出 JSON”。

会修改什么： 只读分析，不修改资产。

### 按后缀清理

什么时候用： 删除资产包中明确不需要的文件，例如 .max、.psd 或指定 LOD 文件。

**怎么用：**

选择要检查的 Project 文件夹。

每行填写一个文件名结尾。

点击“① 递归扫描”。

检查并勾选结果。

点击“② 删除”。

危险： 这是删除功能。必须检查完整列表后再执行，并提前确认版本控制可以恢复。

### 递归抽取资产

什么时候用： 从多层子目录中找出指定类型资产，并集中移动到一个目录。

**怎么用：**

指定来源文件夹和目标文件夹。

选择要抽取的资产类型。

点击“① 递归扫描”。

检查冲突和目标路径。

点击“② 平铺移动”。

支持“恢复上次移动”。

安全说明： 使用 Unity 安全移动，保持 GUID 和已有引用。

> 用了就知道了 总之就是资产移动工具

### Hierarchy 整理

> 好用！！

什么时候用： 一次把大量场景对象放入指定父节点，或创建新的空父物体进行分组。

#### 快速把对象放入固定父节点

只选一个目标父物体。

点击“缓存当前选中为父物体”。

多选需要归入的对象。

点击归入按钮。

缓存不会因为 Selection 改变而丢失。

所以缓存了物体之后可以先去干别的，选择调整别的物体之后再进行整理

#### 创建空父物体

多选场景对象。

输入空物体名称。

点击“创建并归入”。

有了这个功能就可以改变工作方式 先选择想要合并的物体 之后用这个按钮就可以一键组合

将这个功能 和 "快速把对象放入固定父节点" 组合使用  可以将组合起来的物体放到整体的父物体里面

#### 变换风险和补偿节点

当对象带有“旋转 + 非等比缩放”组合0时，直接换父级可能发生形变。工具会阻止普通执行，并显示：

独立补偿：每个风险对象创建一个补偿节点。

共享补偿：同一原父节点下的对象共用一个补偿节点。

没有风险时不会显示补偿选项。

如果目标父物体下面还没有子物体，会优先推荐“整理父物体”：保持它的位置不变，把旋转归零、缩放改为 1。形变大多是因为父物体本身带着旋转和非等比缩放，整理干净后再归入，通常就不需要补偿节点了。这一步支持 Ctrl+Z。

安全说明： 保持世界位置、旋转和缩放，整批操作支持一次 Ctrl+Z。

这个会独立在节点里面生成一个新的父物体 用以防止形变！！！注意！！！

### 场景光源批处理

什么时候用： 批量把选中对象及其子物体中的 Light 改为无阴影、硬阴影或软阴影。

**怎么用：**

在 Hierarchy 选择光源或包含光源的父节点。

选择目标阴影模式。

检查识别到的光源数量。

点击修改按钮。

支持 Ctrl+Z。

### 场景物体阴影

什么时候用： 批量修改 Renderer 是否投射阴影、是否接收阴影。

**怎么用：**

在 Hierarchy 选择对象或父节点。

选择要修改“投射阴影”还是“接收阴影”。

检查 Renderer 数量。

点击修改按钮。

支持 Ctrl+Z。

## 五、资源、模型和预制体

### 模型导入

什么时候用： 连续处理一个或多个外部模型文件夹。

**流程为：**

递归扫描 FBX 和贴图

→ 创建并绑定 URP/Lit 材质

→ 生成 Prefab

**怎么用：**

添加一个或多个来源文件夹。

设置材质和 Prefab 输出选项。

点击“① 扫描并预览整条流程”。

检查每个 FBX 的材质和 Prefab 计划。

点击“② 执行”。

 用的少

### 资源变体

什么时候用： 把场景内已经调整好的 Prefab、FBX 或普通对象保存为新的独立 Prefab。

可选复制：

Prefab

材质

贴图

复制后会把新 Prefab 重新引用到新材质和新贴图，原资产保持不动。

**推荐步骤：**

在 Hierarchy 选择对象。

指定 Prefab、材质和贴图输出文件夹。

设置命名。

点击“分析选中对象”或“仅干运行”。

检查结果后生成。

支持“一键完整撤销本次生成”。

> 用来制作变体的 可以省去重新建造材质球或者复制贴图的时间

### FBX 材质继承

什么时候用： 一个模型的材质引用正确，另一个同结构模型需要复制它的材质。

**怎么用：**

指定参考模型。

指定待修复模型。

点击“对比同名子物体并匹配材质”。

检查匹配结果。

点击“将材质复制到待修复模型”。

工具按照子物体路径或唯一同名 Renderer 进行匹配。

### Prefab Layer

什么时候用： 按资产类型，批量给 Project 中的 Prefab 设置 Layer。

**它怎么判断用哪个 Layer：**

工具不预设任何 Layer 方案，只在你项目里已经定义的 Layer 中挑选：

资产名直接包含 Layer 名时优先匹配，例如 `Rock_Cliff` 对应 `Rocks`。

资产名和 Layer 名属于同一类时也会匹配，例如 `pine_tree` 对应 `Foliage`，`木屋` 对应 `建筑`。

项目里有同一类的大中小多个 Layer（例如 `Rocks_S` / `Rocks_L`、`石头_小` / `石头_大`）时，按资产的占地尺寸选择。尺寸分界可以在页面上调整。

Default、UI 这类引擎自带的 Layer 不参与匹配；什么都匹配不上时保持原样，不会乱改。

**怎么用：**

先在 Project Settings > Tags and Layers 里建好项目需要的 Layer。

在 Project 中选择 Prefab 或文件夹。

点击“分析 Project 选择”。

检查每个 Prefab 的建议 Layer 和匹配依据，不合适的可以直接在下拉框里改。

点击“确认应用 Layer 计划”。

默认只修改仍在 Default 层的节点，已经设置过其他 Layer 的节点保持不变。支持恢复上次修改。

### Tag/Layer

什么时候用： 批量修改 Hierarchy 场景对象及其子物体的 Tag 或 Layer。

**怎么用：**

在 Hierarchy 选择一个或多个对象。

选择目标 Tag 或 Layer。

决定是否包含子物体。

点击应用。

支持 Ctrl+Z。

## 六、材质

### Shader 替换

什么时候用： 批量把 Project 中选中的材质球切换到另一个 Shader。

**怎么用：**

在 Project 中选择材质球。

选择目标 Shader。

点击替换按钮。

如果换 Shader 后贴图丢失，可以使用同页的“恢复丢失属性”尝试从材质序列化数据恢复。

### 选中模型材质贴图

什么时候用： 已经选中场景模型、Prefab 或 FBX，希望快速找到它实际使用的模型、材质和贴图。

**怎么用：**

在 Hierarchy 选择模型，或在 Project 选择 Prefab/FBX。

点击“锁定当前物体并扫描”。

使用“只选模型”“只选材质”“只选贴图”。

需要整理时，在页面下方指定三类目标文件夹并安全移动。

普通模型扫描会忽略 Terrain，防止把当前场景的地形贴图混进结果。

### 选中 Terrain 绘制贴图

什么时候用： 在 Terrain Paint Texture 中选中了某一层，希望在 Project 中找到对应贴图。

**怎么用：**

选择 Terrain。

打开 Paint Texture。

点击需要定位的图层。

点击“在 Project 中选中当前 Paint Texture 贴图”。

> 这个功能是用于直接选中对应的贴图文件而不是选中terrain的素材数据

## 七、场景

### 场景材质替换

什么时候用： 把 Hierarchy 选中对象及其子物体中使用的某个旧材质，统一替换为新材质。

**怎么用：**

在 Hierarchy 选择要处理的对象或父节点。

指定旧材质。

指定新材质。

检查材质槽数量。

点击替换。

支持 Ctrl+Z。

> 一句话:替换物体里面的你不想要的材质 ..

常常用于新导入进来的fbx物体

### 场景材质吸管

什么时候用： 场景模型包含多个材质，不知道鼠标所指区域对应哪个材质球。

**怎么用：**

点击“开始吸取材质”。

在 Scene 视图点击模型表面。

工具会在 Project 中定位对应材质球。

按 Esc 或点击“停止吸取”退出。

### 预制体替换

什么时候用： 把 Hierarchy 中选中的对象替换成另一个 Prefab 或 FBX。

**支持：**

只替换当前选中的对象。

按名称替换当前场景。

高风险：替换所有 Build Settings 场景。

可以选择保留原对象的位置、旋转和缩放。

**安全说明：**

当前场景替换支持 Ctrl+Z。

“所有 Build Settings 场景”会保存场景文件，无法跨场景一次撤销。

> 好用

### FBX 实例检查

什么时候用： 检查场景里是否直接放入了 FBX/OBJ，而不是项目规范要求的 Prefab。

**怎么用：**

选择检查当前选择或已加载场景。

点击“开始检查”。

搜索、筛选、定位或批量选中结果。

会修改什么： 只读检查，不会自动替换对象。

### 烘焙光照

什么时候用： 需要批量开启或关闭模型的 Generate Lightmap UVs，或者烘焙时只想让一部分灯参与。

也可以从菜单 `Tools > Bento > 烘焙光照` 直接打开这一页。

**怎么用：**

在 Hierarchy 中选中要处理的物体或它们的父物体，工具会读取子物体上的模型，并按 FBX/OBJ 资产去重。

点击“一键开启”或“一键关闭”，修改这些模型导入设置里的 Generate Lightmap UVs。

需要撤回时点击“恢复上次 Generate Lightmap UVs 设置”。

在“灯光池与自动烘焙”中，分别把动态光和静态光的父物体加入对应的灯光池，再点击“按灯光池开始烘焙”。

**会修改什么：**

Generate Lightmap UVs 会修改模型资产的导入设置并重新导入。

灯光池只在烘焙期间切换 Light.enabled：动态光全部关闭、静态光全部开启。烘焙完成、停止或取消后恢复原状态，不会隐藏物体，也不会改变 Light Mode。

## 八、可选功能

部分功能依赖额外 Unity 包。没有安装时，对应页面会自动隐藏，其余工具正常使用。

### OBJ 转项目 FBX

需要 Unity 官方 FBX Exporter。

**用途是：**

将 OBJ 导入结果重新导出为项目 FBX。

创建项目材质。

在确认 FBX 和材质引用正常后，扫描并删除可安全移除的 OBJ/MTL 源文件。

> 少用

### AI/MCP

需要 MCP for Unity。

用途是让 AI：

读取选择和场景层级。

生成只读审查结果。

生成资产整理或 Hierarchy 整理草案。

调用 FBX 实例检查。

AI 默认不能绕过工具箱直接执行高风险资产移动或场景修改，最终写入仍需用户在 Unity 页面确认。

## 九、推荐工作流

### 导入一个新资产包

`文件夹收藏 → 模型导入 → 选中模型材质贴图 → 批量重命名 → 资产移动 → Prefab Layer`

### 整理一个现有场景

`FBX 实例检查 → Hierarchy 整理 → 场景材质替换 → 场景光源批处理 → 场景物体阴影`

### 把场景中调好的对象保存为新资产

`资源变体 → 检查新材质和贴图引用 → 批量重命名 → 资产移动`

### 版本控制提交前

`检查场景是否发粉 → 检查移动清单 → 只提交本次修改涉及的资源`

## 十、遇到问题先检查

是否处于 Play Mode。

当前选择是在 Hierarchy 还是 Project。

页面要求的是资产、文件夹、Prefab、FBX 还是场景对象。

是否先执行了扫描或分析。

计划列表中是否有黄色或红色警告。

FBX Exporter 或 MCP 是否属于当前功能的可选依赖。

资产操作出错时，先停止继续操作，查看“操作历史”或版本控制，不要重复执行。
